Nile-Gate is a software system that will operate a range of agents in various space related missions:
The system contains the following agents so far:

1. anubis-guide-v1.0 — the guide of all agents that will be added to the system.
2. horus-vision-v1.0 — this agent conducts centralized coordination of all the agents and ensures accurate cooperation.
3. sobek-archive-v1.0 — the mind keeper and dictionary of the system. Basically the central knowledge database of the system.
4. seth-guard-v1.0 — the security agent of the system.
5. ra-pathfinder-v1.0 — the planner of the system.
6. thoth-strategy-v1.0 — the strategist of the system.
